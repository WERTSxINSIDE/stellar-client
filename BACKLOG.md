# Бэклог

## Готово

### 1. Витрина конфигов и видео-отзывов
- [x] Загрузка конфигов и видео-отзывов пользователями (файл или ссылка).
- [x] Рейтинги (1–5) и сортировка по рейтингу, карточки с описанием.
- [x] Модерация в админке `/dashboard/admin/showcase`: одобрить / отклонить / скрыть / вернуть.
- [x] Награда на баланс за принятый материал (по умолчанию 75 ₽ за конфиг, 150 ₽ за видео; админ может изменить).
- [x] Публичная витрина `/community` (вкладки Live / Конфиги / Видео-отзывы).
- [x] API: `/api/showcase`, `/api/showcase/rate`, `/api/showcase/[id]/download`, `/api/admin-showcase`.

### 1.1. Платные конфиги
- [x] Автор задаёт цену при загрузке: `0` — бесплатно, иначе от 10 до 10 000 ₽.
- [x] Покупка с баланса: 100% цены получает автор; списание и зачисление в одной транзакции.
- [x] История баланса (`showcase_purchase`, `showcase_sale`), уведомления покупателю и автору, событие в Live-ленте.
- [x] Скачивание платного конфига только автору, админу и покупателю; защита от повторной покупки, самопокупки и нехватки средств.
- [x] В витрине видны цена, число продаж, статусы «Куплено» / «Ваш материал»; в админке — цена и продажи.
- [x] API: `/api/showcase/[id]/buy`.

### 1.2. Отзывы покупателей и страница материала
- [x] Страница `/community/[type]/[id]`: описание, автор, цена, покупка, скачивание, рейтинг и отзывы.
- [x] Текстовый отзыв доступен только после покупки платного конфига (для бесплатных и видео — любому авторизованному, кроме автора).
- [x] Оценка 1–5 и текст отзыва, защита от повторного отзыва и отзыва на свой материал.
- [x] Ответ автора на отзыв, отображение ответа в списке.
- [x] Поиск, теги, фильтры по цене и сортировка (цена, популярность, рейтинг, новые) в `/community`.
- [x] API: `/api/showcase/[id]`, `/api/showcase/[id]/view`, `/api/showcase/rate`, `/api/showcase/[id]/reply`.

### 1.3. Кабинет автора
- [x] Страница `/dashboard/author`: заработок, продажи, просмотры, конверсия просмотр → покупка.
- [x] Топ материалов, статус модерации и причина отклонения.
- [x] История продаж: материал, сумма, дата и username покупателя (без email, баланса и HWID).
- [x] API: `/api/author/stats`.

### 2. Live-лента и «сейчас онлайн»
- [x] Лента реальных событий: активации ключей, запуски лаунчера, достижения, отзывы, принятые материалы.
- [x] Блок «сейчас онлайн» и счётчик запусков за сутки.
- [x] Автообновление каждые 20 секунд (polling).
- [x] Приватность: в ленте только username и аватар, без email, баланса, HWID и точной даты окончания подписки.
- [x] API: `/api/feed`; события пишутся в `activity_events`, запуски троттлятся (не чаще раза в 10 минут на пользователя).

### 3. Поддержка 2.0
- [x] Категории тикетов (оплата, доступ, HWID, лаунчер, другое) и фильтры в админке.
- [x] CSAT: оценка 1–5 и комментарий после закрытия тикета, средний балл в админке.
- [x] Шаблоны ответов: создание, удаление и вставка в ответ прямо из тикета.
- [x] Вложения в тикетах: изображения, PDF, TXT, LOG, ZIP, RAR, 7Z (до ~1,8 МБ исходного файла).
- [x] Статусы `open` / `pending` / `closed`, счётчики непрочитанных для игрока и админа.
- [x] API: `/api/support`, `/api/support-templates`.

### 4. Пополнение баланса
- [x] Пресеты 50 / 150 / 200 / 300 / 400 ₽ на странице покупок `/pricing#topup`.
- [x] Ссылки FunPay настраиваются администратором: `/dashboard/admin/payments`.
- [x] Пока ссылка не задана — кнопка неактивна с подписью «Скоро».
- [x] В кабинете, в разделе «Баланс», осталась кнопка-переход на пополнение и активация промокода.
- [x] Оплата через FunPay выдаёт промокод, который активируется в существующем поле промокода (баланс зачисляется только после активации).
- [x] API: `/api/topup`, `/api/admin-payments`; ключи настроек `topup_50_url` … `topup_400_url`.
